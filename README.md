# NovelPress 小说排版工具

一个网页工具，帮你把写好的小说（txt 或 epub 文件）排成**可以拿去印刷的 PDF**。

不需要安装任何软件，用浏览器打开就能用。

---

## 这个工具能做什么

- **导入小说**：支持 `.txt` 和 `.epub` 文件，也可以直接粘贴文本
- **自动识别章节**：自动把"第X章""Chapter X"之类的内容分成章节，也能手动调整
- **自动生成书的样子**：
  - 书名页（第一页写书名）
  - 目录页（自动列出每章和第几页）
  - 正文从右页开始（符合印刷装订习惯）
  - 每一章的开头自动落在右页，前一章结束在右页时自动补一张空白页
- **可调排版**：
  - 页面大小、页边距、出血
  - 正文字体（思源宋体 / 思源黑体）、字重、字号
  - 行距、段间距、首行缩进
  - 页眉页脚：开关、内容、字体、页码格式
  - 书名、目录页开关
- **两端对齐**：正文右侧也会贴齐边界，视觉上像正式出版物
- **预览区直接改章节标题**：双击预览里的章节名就能改，左侧列表同步更新
- **导出 PDF**：A5 开本，含 3mm 出血和裁切角线，可直接送印

## 如何使用

### 第一次使用（安装字体）

这个工具**需要思源字体才能显示和导出中文**。第一次使用前：

1. 进入仓库的 `assets/fonts/` 文件夹
2. 下载里面全部 14 个 `.ttf` 字体文件
3. 把它们**安装到你的电脑**：
   - **Windows**：全选这 14 个文件，右键 → **安装**
   - **Mac**：全选，双击，在字体册里点"安装字体"

**电脑没装字体，网页里预览会显示方块，导出 PDF 也可能缺字。**

### 打开工具

**方式一（推荐）：用在线版**

打开这个网址即可：
https://euclase2333.github.io/novelpress/

**方式二：本地运行（离线）**

1. 把整个项目下载到电脑
2. 打开命令行，进入项目文件夹，运行：
python -m http.server
3. 浏览器访问 `http://localhost:8000`

## 操作步骤

### 第 1 步：导入小说

左侧"输入区"：

- 点 **导入文件**，选一个 `.txt` 或 `.epub`
- 或者直接在文本框里**粘贴**小说的内容

### 第 2 步：确认章节

导入后，左侧会出现章节列表。

- 章节识别对了 → 继续
- 识别不对 → 可以**双击章节名改名**、**拖拽调整顺序**、**删除**、**手动插入**
- 如果完全没识别出章节 → 点"自动识别章节"按钮

### 第 3 步：填书名

左侧输入框里填书名。不填的话，默认用文件名。

### 第 4 步：调整排版

右侧"格式选项"里可以调：

- **页面**：大小、出血、上下内外边距
- **排版**：字体、字号、行距、缩进
- **页眉页脚**：开关、内容、是否显示页码

改完马上能在中间看到效果。

### 第 5 步：预览检查

中间的"预览区"：

- 顶部可以切换 **单页 / 双页** 视图
- **滚轮上下滚动**查看每一页
- 点左侧章节列表里的**章节名**，可以跳到那一章
- **双击章节标题**可以直接改字
- 打开 **辅助线**，能看到页边距（橙色虚线）、正文区（绿色虚线）、出血（浅蓝色）

### 第 6 步：导出 PDF

右侧面板底部（或顶部）有 **导出 PDF** 按钮。

点击后浏览器会下载一个 PDF 文件。

## 重要：导出后还要做一件事

**导出的 PDF 是普通 PDF，还需要"转曲"才能送印刷厂。**

转曲 = 把文字变成图形，避免印刷厂电脑没装字体导致乱码。转曲后，字体就"固定"在文件里了。

**转曲方法（任选一个）**：

1. **Adobe Acrobat Pro**（推荐）
- 打开 PDF
- 菜单 **文件 → 另存为其他 → 优化 PDF**
- 勾选"将文字转换为轮廓"
- 保存

2. **在线转曲网站**
- 搜索"PDF 转曲 在线"
- 上传 PDF，等待处理完下载

3. **交给印刷厂**
- 很多印刷厂会帮你转曲，直接问客服即可

**为什么工具本身不做转曲？**

浏览器里做转曲速度慢、文件体积大、兼容性也不一定好。用专业工具（Acrobat）转曲质量最稳。所以这个小工具把转曲留给下游处理。

## 常见问题

**Q：导入后预览是方块、导出 PDF 也没有中文？**
A：说明你电脑没装思源字体。见上面"第一次使用（安装字体）"。

**Q：导出的 PDF 打印会不会太小 / 太大？**
A：默认是 A5 开本（148×210mm），跟普通小说差不多。需要别的尺寸，在右侧"页面"里改。

**Q：想做 A4 或别的开本怎么办？**
A：右侧"页面"里把宽度和高度改成你要的尺寸（比如 A4 是 210×297mm）。

**Q：目录里显示"（无标题）"怎么办？**
A：说明那一章没有识别出标题。在左侧章节列表里双击改个名字就行。

**Q：可以改页眉页脚的内容吗？**
A：可以。右侧"页眉页脚"里有输入框。`{bookTitle}` 是个变量，会自动替换成书名。

**Q：导出的 PDF 打开有警告"无法提取嵌入的字体"？**
A：这是 PDF 里的一个提示，不影响使用。如果要去印刷，转曲后这个警告会消失。

**Q：能导出 EPUB 吗？**
A：不能。这个工具专门做 PDF 印刷文件。

## 这个工具是怎么做的

如果你想了解技术细节：

- 纯前端网页，不需要服务器
- 用 JavaScript 写成，PDF 生成用 pdf-lib

- 开源，源代码就在这个仓库里

**不需要懂代码就能使用。**
